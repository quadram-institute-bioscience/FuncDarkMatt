# Mapping File Usage Guidelines

## Choosing the Right Mapping File

| Use Case | File | Strategy |
|----------|------|----------|
| High-confidence functional annotation | `RXN_UNIREF90.txt` | EC-Number Based, Exact Pfam, EC + Exact Pfam |
| Higher coverage | `RXN_UNIREF90.txt` | Any Pfam Mapping |
